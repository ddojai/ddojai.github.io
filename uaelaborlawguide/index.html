앱 소개

계약서에서 직접 찾은 수습·통보·연차 값을 질문과 함께 남기는 확인 노트입니다. 관련 조항의 외부 출처를 직접 열어 보고 확인 상태를 표시합니다.

적용 버전

이 안내는 1.1.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

수습·통보·연차 값과 단위
상황별 확인 질문과 조항 링크
직접 읽은 상태·시각·노트 저장

자주 묻는 질문

입력한 통보일수가 합법인지 판정하나요?

숫자의 적법성이나 퇴사 가능일을 판정·계산하지 않습니다. 질문과 출처를 확인하는 참고 도구입니다.

출처를 읽었음 표시는 권리 확인인가요?

사용자가 어디까지 읽었는지 남기는 표시입니다. 법적 권리나 적법성을 확인한 결과가 아닙니다.

출처 링크가 열리지 않으면 노트도 없어지나요?

노트는 유지됩니다. 다시 시도하거나 주소를 복사할 수 있습니다. 법 개정 여부와 아랍어 원문은 행동 전에 직접 확인하세요.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
