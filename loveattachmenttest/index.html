지원 페이지

앱 소개

12문항에 답하고 불안과 회피 두 축으로 내 결과를 살펴보는 테스트입니다. 결과 코드를 주고받거나 한 기기에서 답해 두 사람의 결과를 함께 볼 수 있습니다.

적용 버전

이 안내는 1.2.1 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

두 축 점수와 네 유형 경계
두 사람 지도와 상황별 연락 가이드
검사 이력과 9:16 결과 카드

자주 묻는 질문

심리 진단에 사용할 수 있나요?

재미와 자기 이해를 위한 자체 문항입니다. 의학적·심리적 진단이나 관계의 미래를 판단하는 검사가 아닙니다.

상대 결과를 어떻게 함께 보나요?

상대가 보낸 결과 코드를 입력하거나 한 기기에서 상대가 검사할 수 있습니다. 저장하지 않고 한 번만 보는 선택도 있습니다.

결과를 보내면 자동으로 공개되나요?

직접 공유한 코드나 카드가 선택한 상대·앱으로 전달됩니다. 기기에 저장된 검사 기록이 자동 게시되지는 않습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
