차량 정비 기록

지원 페이지

앱 소개

정비와 주유, 계기판 확인을 기록하고 다음 교체 일정을 살펴봅니다. 주행 기록이 충분하면 주행 페이스로 교체 예상일을 계산합니다.

적용 버전

이 안내는 1.5.1 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

여러 정비 항목·주유 이력
교체·검사·보험 일정과 선택 알림
차량별 비용 통계와 CSV 공유

자주 묻는 질문

교체 예상일은 정비소 진단인가요?

아닙니다. 입력 기록과 설정한 주기로 계산한 참고값입니다. 차량 설명서와 정비소 안내에 맞게 주기를 확인하세요.

자동으로 주행거리를 읽나요?

계기판과 정비·주유 값은 직접 기록합니다. 차량이나 계좌를 연결해 읽는 도구가 아닙니다.

검사 기한은 앱만 믿으면 되나요?

안내문 기준 적용을 직접 확인한 차량의 일반 검사 기간만 안내합니다. 특례와 실제 기한은 검사 안내문을 확인하세요.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
