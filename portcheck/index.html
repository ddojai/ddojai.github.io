데이터는 어디에 저장되나요?

모든 투자 데이터는 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다.

시세는 어떻게 불러오나요?

한국 공공데이터포털(data.go.kr) API를 통해 실시간 시세를 조회합니다.

API 키는 어떻게 설정하나요?

설정 화면에서 공공데이터포털에서 발급받은 개인 API 키를 입력할 수 있습니다.

광고가 표시되는 이유는?

앱 개발 및 유지 비용 지원을 위해 Google AdMob 광고가 표시됩니다.
