컬러 타일 합치기

지원 페이지

앱 소개

6×6 보드에서 같은 숫자가 이어진 그룹을 합치는 퍼즐입니다. 먼저 결과를 보고 다시 눌러 합치거나 직전 한 수를 되돌릴 수 있습니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

연결 그룹·점수·남는 칸 미리보기
직전 한 수 무료 되돌리기
최고점·누적 기록과 수동 공유

자주 묻는 질문

대각선으로 붙은 타일도 합쳐지나요?

상하좌우로 같은 숫자가 2개 이상 연결되어야 합니다. 대각선은 연결로 세지 않습니다.

힌트가 가장 좋은 수를 알려 주나요?

현재 가장 큰 연결 그룹의 예시를 보여 줄 뿐 최선의 수를 보장하지 않습니다.

앱을 닫아도 진행 중인 판이 저장되나요?

진행 중인 판은 앱을 닫으면 이어 할 수 없습니다. 최고점과 누적 기록은 기기에 남습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
