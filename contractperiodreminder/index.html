계약 만료 알리미

지원 페이지

앱 소개

계약 만료일과 직접 확인한 통보 기한을 따로 기록합니다. 먼저 판단할 날짜가 가까운 계약부터 살펴보고 결정 기록을 남길 수 있습니다.

적용 버전

이 안내는 1.1.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

만료일·통보 기한·다음 알림 구분
판단일 순서와 검색·유형 필터
결정 기록과 기기 알림

자주 묻는 질문

통보 기한을 자동으로 계산하나요?

아닙니다. 계약서 등에서 직접 확인한 날짜를 적으며 모르면 미입력으로 남깁니다.

계약을 자동 갱신하거나 해지하나요?

아닙니다. 날짜가 지나도 계약은 기록으로 남고 자동 연장·해지·상대방 통보를 하지 않습니다.

날짜가 있는데 알림이 오지 않아요.

카드의 다음 알림 예약 상태와 iOS 알림 권한·집중 모드를 확인하세요. 기록 날짜와 실제 알림 전달은 별개입니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
