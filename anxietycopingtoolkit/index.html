앱 소개

잠시 숨을 고르고 감각을 살피며 마음을 기록하는 도구함입니다. 호흡과 그라운딩, 확언, 감사·기분 기록을 이용할 수 있습니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

호흡 패턴과 1분 호흡
5-4-3-2-1 감각 그라운딩
확언·감사·기분 기록과 선택 알림

자주 묻는 질문

위급할 때도 앱만 쓰면 되나요?

진단이나 치료, 긴급 대응을 대신하지 않습니다. 한국어 도움 안내에서 109·119·112를 확인하고 전화 앱을 열 수 있습니다.

기록이 오래되면 자동으로 지워지나요?

기분과 감사 기록을 자동 삭제하지 않습니다. 삭제는 앱에서 직접 선택하고 확인합니다.

인터넷 없이 쓸 수 있나요?

호흡·그라운딩과 기록은 오프라인으로 사용할 수 있습니다. 외부 방침이나 전화 앱을 여는 동작은 기기와 서비스 상태의 영향을 받습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
