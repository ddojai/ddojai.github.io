앱 수익 시뮬레이터

지원 페이지

앱 소개

광고·구독·유료 다운로드의 수익 가정을 나란히 비교합니다. 실제 매출을 연결하지 않고 직접 입력한 트래픽과 전환율로 계산합니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

최대 3개 시나리오 월 기준 USD 비교
입력 하나를 20% 바꿨을 때 결과 차이 보기
작업대 저장과 공유 전 가정 미리보기

자주 묻는 질문

결과가 실제 수익 예측인가요?

아닙니다. 입력한 가정을 계산한 값이며 세금·환불·획득비·환율 등은 반영하지 않습니다.

DAU를 구독 결제 대상자에 그대로 넣어도 되나요?

하루 활성 사용자와 한 달 결제 대상자는 기간과 분모가 다릅니다. 각 모델의 입력 항목과 결과 옆 분모를 확인하세요.

광고망이나 스토어 계정이 필요한가요?

필요하지 않습니다. 실제 매출이나 계정을 읽지 않고 오프라인으로 계산합니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
