지원 페이지

앱 소개

받은 비자 견적을 아홉 항목으로 적고 나·회사·미확인 부담을 나누어 봅니다. 견적 총액과 입력 소계의 차이와 아직 모르는 항목을 확인하는 도구입니다.

적용 버전

이 안내는 1.1.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

9개 견적 항목과 포함·제외
본인·회사·미확인 부담과 총액 차이
직접 환율 입력·한 건 저장·공유 미리보기

자주 묻는 질문

정부 수수료를 자동으로 채워 주나요?

앱에는 정부 수수료 금액이 들어 있지 않습니다. 받은 견적이나 연결된 공식 안내에서 직접 확인해 적습니다.

빈칸과 0은 같은가요?

빈칸은 미확인이고 0은 0으로 확인한 금액입니다. 금액이 없는 항목을 0으로 합의했다고 처리하지 않습니다.

환율은 실시간인가요?

시장 환율을 가져오지 않습니다. 1 AED당 환율을 직접 입력했을 때만 본인 부담 기록을 환산합니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
