지원 페이지

앱 소개

흙을 확인하고 실제 물준 날과 다시 확인할 날을 따로 남깁니다. 화분별 돌봄 기록과 사진, 비료·분갈이 일정을 관리할 수 있습니다.

적용 버전

이 안내는 1.3.2 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

물 줬어요·아직 촉촉해요 기록
물주기 이력·사진·돌봄 일정
위젯 조회와 iOS 17 이상 중간 위젯 기록

자주 묻는 질문

알림이 오면 반드시 물을 줘야 하나요?

흙을 확인하라는 일정이며 흙의 상태를 자동 판단하지 않습니다.

아직 촉촉해요를 누르면 무엇이 바뀌나요?

물준 기록은 유지하고 다시 확인할 날짜만 미룹니다. 위젯에서는 내일로 미룹니다.

위젯에서 눌렀는데 앱 기록이 바로 바뀌지 않아요.

위젯 기록은 앱을 열 때 반영됩니다. 앱에서 반영된 기록을 확인하고 되돌릴 수 있습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
