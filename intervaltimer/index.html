앱 소개

한국어 루틴 글을 붙여넣고 해석된 동작과 시간을 확인해 시작합니다. 시간 구간과 직접 완료하는 횟수 구간을 나누어 사용할 수 있습니다.

적용 버전

이 안내는 1.1.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

원문과 해석 미리보기·수정
시간형·횟수형·휴식·세트
프리셋·내 루틴·완료 기록

자주 묻는 질문

횟수 운동의 시간을 자동으로 추정하나요?

아닙니다. 탭해서 넘기거나 사용자가 지정한 개당 시간으로 환산합니다.

읽지 못한 줄이 있으면 시작할 수 있나요?

해당 줄을 수정하거나 명시적으로 제외해야 합니다. 모호한 휴식 배치도 확인합니다.

앱을 완전히 종료해도 운동이 이어지나요?

완전히 종료하면 진행 중 운동은 이어지지 않습니다. 잠금 중 안내는 늦거나 빠질 수 있고 수동 구간에서는 직접 완료해야 합니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
