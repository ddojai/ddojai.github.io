앱 소개

친구와 같은 다섯 문항에 답하고 두 결과를 한 화면에서 보는 테스트 모음입니다. 혼자 답하고 결과 카드를 공유하거나 지난 결과를 다시 볼 수도 있습니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

14개 테스트와 앞 문항으로 돌아가기
폰을 건네 친구와 결과 나란히 보기
최근 내 결과 50개와 9:16 공유 카드

자주 묻는 질문

친구 답변도 저장되나요?

친구 답변과 결과는 저장하지 않습니다. 비교를 마치면 사라지고 내 결과로 돌아갑니다.

매주 새 테스트가 나오나요?

정기 발행은 하지 않습니다. 제공된 14개 테스트를 이용할 수 있습니다.

성격 진단이나 궁합 검사인가요?

재미로 보는 자체 테스트입니다. 심리·의학 진단이나 성격·건강·관계를 판단하는 검사, 궁합 예측 도구가 아닙니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다. 친구 답변과 결과는 저장하지 않으며 비교를 끝내면 사라집니다. 내 결과는 최근 50개를 기기에 보관하고 직접 전체 삭제할 수 있습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
