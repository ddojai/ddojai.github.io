지원 페이지

앱 소개

사진에서 대표색을 최대 5개 찾고 원하는 칸을 직접 바꿉니다. 글자·배경 대비를 확인한 뒤 팔레트 전체를 코드로 복사할 수 있습니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

사진 대표색·지점 선택·HEX 편집
한 쌍의 텍스트 대비비와 기준별 판정
CSS·Tailwind·Flutter·SwiftUI·JSON 복사

자주 묻는 질문

사진이 저장되거나 전송되나요?

선택한 사진은 기기 안에서 처리하며 앱은 사진·촬영 정보를 저장하거나 전송하지 않습니다. 저장 팔레트에는 색과 이름, 만든 시각만 남습니다.

AA 통과면 웹사이트 전체가 접근성을 충족하나요?

선택한 글자·배경 한 쌍의 텍스트 대비만 확인합니다. 웹사이트 전체나 인쇄 색, 색각 대응을 인증하지 않습니다.

사진에서 찾은 색이 다섯 개보다 적어요.

실제로 찾은 색 수만 표시합니다. 같은 색을 반복해서 다섯 칸으로 채우지 않습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다. 시스템 사진 선택 화면에서 고른 사진만 기기 안에서 처리하고 사진·촬영 정보는 저장하거나 전송하지 않습니다. 저장 팔레트에는 색·이름·만든 시각이 남습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
