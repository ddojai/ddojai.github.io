지원 페이지

앱 소개

운동의 세트별 횟수와 무게를 기록합니다. 같은 운동의 직전 기록을 보며 지난 값을 가져와 직접 수정하고 저장할 수 있습니다.

적용 버전

이 안내는 1.3.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

세트별 횟수·무게 직접 저장
직전 값 사용·수동 휴식 타이머
운동 통계·참고 1RM·CSV 내보내기

자주 묻는 질문

이전 세트 기록은 유지되나요?

기존 운동 기록을 유지하며 세트별 횟수와 무게를 확인할 수 있습니다.

1RM 추정은 실제로 들어 보라는 뜻인가요?

아닙니다. 공식에 따른 참고값으로 실제 최대 중량이나 안전한 시도를 보장하지 않습니다.

운동 자료에 인터넷이 필요한가요?

외부 운동 자료를 불러올 때 wger에 요청합니다. 개인 세트 기록을 개발자 서버에 업로드하지 않습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다. 외부 운동 자료를 불러올 때 wger 서비스에 요청하며 해당 서비스에 접속 정보가 전달될 수 있습니다. 개인 운동 기록은 이 요청에 넣지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
