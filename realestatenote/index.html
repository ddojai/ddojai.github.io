앱 소개

방문한 곳의 동·층·향·소음·주차를 같은 다섯 칸에 기록합니다. 두세 곳을 나란히 보고 미확인인 칸을 다음 방문에서 다시 살펴볼 수 있습니다.

적용 버전

이 안내는 1.4.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

관찰 다섯 칸과 초안 보관
2~3곳 비교와 미확인 표시
사진·메모·선택 거래자료 조회

자주 묻는 질문

주소를 꼭 입력해야 하나요?

별칭만으로 저장할 수 있습니다. 주소와 단지명은 선택입니다.

비교 결과로 순위를 매기나요?

순위나 종합 점수를 자동으로 매기지 않습니다. 직접 쓴 관찰과 미확인 칸을 같은 순서로 보여 줍니다.

거래자료는 자동으로 실시간 확인하나요?

저장한 관심 단지에서 직접 조회할 때 국토교통부 신고 자료를 요청합니다. 신고 시차·정정과 조회 조건에 따라 결과가 달라질 수 있습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다. 직접 거래 조회를 누르면 법정동 지역 코드와 거래년월을 국토교통부 공공데이터 API로 보냅니다. 지도 열기를 선택하면 주소를 외부 지도 서비스로 넘기며 방문 사진·메모를 거래 조회로 보내지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
