앱 소개

국내 상장 종목을 재무 지표로 걸러 보고 비교합니다. 공시 재무와 전 거래일 주가의 기준 시점을 확인하며 참고할 수 있습니다.

적용 버전

이 안내는 1.4.8 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

PER·PBR·ROE 등 필터와 퀀트 점수
가중치·프리셋·관심종목 메모
OpenDART·공공데이터 시점 표시

자주 묻는 질문

실시간 시세인가요?

아닙니다. 공공데이터의 전 거래일 종가와 공시 재무를 사용하며 마지막으로 받은 자료의 기준일을 확인해야 합니다.

데이터를 받으려면 무엇이 필요한가요?

설정에 본인이 발급한 OpenDART API 키와 공공데이터포털 서비스키를 입력해야 합니다. 앱에는 공용 키가 없습니다.

점수가 높으면 매수 추천인가요?

투자 추천이나 자문이 아닙니다. 점수는 지표와 가중치로 계산한 참고값이며 투자 판단은 별도로 해야 합니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다. 자료 조회에는 입력한 API 키가 해당 공급자(OpenDART·공공데이터포털)로 전달됩니다. 키와 관심종목·메모·받은 자료는 기기에 저장하며 키는 지원 문의로 보내지 마세요.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
