지원 페이지

앱 소개

막힌 칸에서 먼저 볼 곳과 짧은 이유를 살펴보는 스도쿠입니다. 다음 숫자는 직접 넣고 메모·되돌리기와 한 판 저장을 사용할 수 있습니다.

적용 버전

이 안내는 1.2.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

볼 곳→이유→직접 입력
후보 메모·되돌리기·이어하기
오늘의 세 난이도와 도움 사용 기록

자주 묻는 질문

이유를 보면 숫자가 자동으로 들어가나요?

자동 입력하지 않습니다. 볼 칸과 근거를 보고 숫자는 직접 넣습니다.

모든 막힌 상태를 설명하나요?

두 가지 기본 방식으로 설명할 수 있는 상태만 다룹니다. 설명할 수 없으면 그 상태를 안내합니다.

업데이트 후 오늘의 판이 달라졌어요.

생성 방식이 바뀌면 그날의 새 판이 이전 버전과 달라질 수 있습니다. 진행 판과 지난 기록은 별도로 보존합니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
