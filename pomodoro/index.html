뽀모도로 - 집중 타이머

지원 페이지

앱 소개

집중과 휴식을 번갈아 진행하고 실제 집중 분을 기록합니다. 멈춘 집중도 기록으로 남겨 오늘의 토마토 선반에서 돌아볼 수 있습니다.

적용 버전

이 안내는 1.5.1 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

프리셋과 1~90분 길이 설정
완료·중단 기록과 태그·주·월 흐름
완료 알림·노이즈·지원 iOS 위젯

자주 묻는 질문

중간에 멈추면 기록이 없어지나요?

1분 이상 집중한 기록은 반쪽 토마토로 보관합니다. 일시정지와 끝내기는 구분됩니다.

잠금 중에도 완료를 알 수 있나요?

완료 알림과 지원 iOS의 Live Activity를 사용할 수 있습니다. 알림 표시·소리는 기기 설정과 상태의 영향을 받습니다.

옛 기록에 집중 분이 없는 이유는요?

이전 버전의 날짜별 세션 수는 유지하지만 기록되지 않은 집중 분을 추정해서 채우지 않습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
