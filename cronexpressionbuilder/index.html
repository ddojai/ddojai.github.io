지원 페이지

앱 소개

숫자 5필드 cron 식을 붙여넣고 다음 5회 실행 시각을 확인합니다. 실행 날짜가 포함되는 이유와 시간대 차이를 보고 복사할 수 있습니다.

적용 버전

이 안내는 1.1.0 버전의 스토어 출시 후 해당 버전에 적용됩니다. 설치한 버전에 따라 기능이 다르며 이전 버전의 개인정보 설명은 공통 방침에서 확인해 주세요.

주요 기능

원문 보존과 다섯 필드 편집
날짜·요일 규칙과 다음 5회
기기·UTC·IANA 실행 시간대 선택

자주 묻는 질문

초가 들어간 6필드 식도 되나요?

숫자 5필드 형식만 지원합니다. 6·7필드, 이름·매크로·명령이 붙은 줄은 자동 변환하지 않습니다.

날짜와 요일을 모두 지정하면 어떻게 되나요?

둘 다 제한하면 어느 한쪽이 맞는 날을 포함합니다. 결과에서 날짜·요일 중 어느 조건이 맞았는지 확인하세요.

서버에 작업을 등록하나요?

이 앱은 실행 시각을 기기에서 계산하는 도구입니다. 실제 예약 작업 등록이나 서버 실행을 하지 않습니다.

개인정보 요약

저장한 기록과 설정은 이 기기의 앱 저장소에 보관되며 개발자 서버로 자동 업로드하지 않습니다.이 버전에는 광고와 추적이 없습니다. 외부 링크를 직접 열면 연결한 서비스의 처리가 적용됩니다.공유는 직접 선택한 내용만 고른 앱으로 보냅니다.OS 설정에 따라 기기 백업에 앱 데이터가 포함될 수 있으며 앱 삭제로 백업이나 받은 쪽 사본까지 지워지지는 않습니다.
